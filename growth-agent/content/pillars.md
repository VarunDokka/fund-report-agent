# Content Pillars

Re-ranked weekly by `growth-analyst` from real data — never from memory of what the strategy used to be. If a new pillar starts outperforming the two below, this file says so, even if it contradicts last month's plan. See the self-improving loop rules in the root [CLAUDE.md](../CLAUDE.md).

**Last ranked:** 2026-08-16 (seed ranking, from the 90-day pull in [instagram_analysis_varun_dokka.md](../intel/source-research/instagram_analysis_varun_dokka.md)). No fresh daily data has been ingested yet — see [daily-log.csv](../analytics/daily-log.csv).

## 1. Exam-stress / student-burnout POV — proven, core pillar

3 posts = ~65% of all views this quarter (395K of 607K). Individual posts ran 5–25x the account average. Post more of these, faster, especially around exam periods and deadlines — the format has clear seasonal peaks (May 2026 = exam season = concentration of the account's best posts).

**Format:** Hook-first talking head, POV text overlay, "anchor + punch" text density. See [voice-guide.md](../brand/voice-guide.md).

## 2. Internship / corporate-intern humor — proven, repeatable #2

90–300 accounts-engaged across 8+ posts. Not viral-outlier territory, but consistent. Brief's recommendation: build this into a named series ("POV: you're an intern and...") so people start expecting and seeking it out.

**Format:** Hook-first talking head, same POV-caption convention as pillar 1.

## 3. Mastery / Stoic identity layer — pillar-in-progress, not yet data-validated

The Da Vinci/Marcus Aurelius material: bymiilan-style emotion/quote entries, the Richie-arc diary entries, Personal Growth confessions, PE/finance reflection pieces. This is the identity/movement layer described in [identity.md](../brand/identity.md)'s Aspirational Archetype section — it carries the same *weight* as pillars 1–2 in how seriously it's treated, but it does not yet have its own performance data. Logged as a hypothesis in [experiments.md](../coaching/experiments.md), re-ranked here once real numbers exist. Should show up every few posts, not as filler but as the throughline that makes the account read as one story instead of scattered content.

**Format:** Sit-down philosophy ("prestige" format — low volume, one consistent camera setup), or voiceover-over-stillness for bymiilan-style entries.

## 4. Personal / occasional — not strategy

Gym check-ins, dating bits, football, nostalgia, generic wellness walks, music. Consistently the weakest performers (60–150 accounts engaged) even when they cost real effort to film. Keep posting for personal reasons if Varun wants to, but don't expect these to grow the account, and don't let them dilute a page that's starting to have a clear identity.

**Caution on vegetarian-fitness content specifically:** vegetarian fitness is core to the "body" third of the freedom narrative in identity.md, but generic gym check-ins are exactly the kind of niche/personal content that underperforms in the data. The fix per [voice-guide.md](../brand/voice-guide.md)'s script content rule: don't post gym content as a check-in — post it as proof/story ("I got abs without eating chicken — here's what actually mattered") with a specific personal story attached, or fold it into the mastery pillar (#3) rather than treating it as filler.
